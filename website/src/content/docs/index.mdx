## What you get

<CardGrid>
	<Card title="Errors that say where" icon="warning">
		`fmt.Errorf("%s: %w", trace.Here(), err)` reads `service.go:42 users.(*Service).Create: duplicate key`.
		`errors.Is` and `errors.As` see through it as before.
	</Card>
	<Card title="Helpers that name their caller" icon="right-arrow">
		`trace.Caller(1)` is the line that called your helper, so wrappers and loggers point at the code that
		matters, not at themselves.
	</Card>
	<Card title="No allocations" icon="rocket">
		Capturing a frame and formatting it, into a buffer, a string or a `slog` value, allocate nothing once its
		call site has been used. Tests count every allocation.
	</Card>
	<Card title="Made for slog" icon="list-format">
		A frame logs as text through `slog.LogValuer`, and holds the same program counter as `slog.Record.PC`, so
		a helper can log with its caller's line as the source.
	</Card>
	<Card title="Right with inlining" icon="approve-check">
		Frames are resolved with `runtime.CallersFrames`, so a function the compiler inlined is still the one named.
		Tests check it on a helper that really is inlined.
	</Card>
	<Card title="Small API" icon="puzzle">
		Two functions and one type. Nothing to configure and no dependencies beyond the standard library.
	</Card>
</CardGrid>

## Faster than v1, with nothing to allocate

<div class="landing-lead">
	v2 keeps the program counter and resolves it once per call site, where v1 resolved and formatted it on every call.
	Getting a frame as a string went from 437 ns and 9 allocations to 72.7 ns and none.
</div>

## Coming from v1

<div class="landing-lead">
	v1 returned a string built from flags. v2 returns a frame with one text form, and methods for the function,
	file and line. `FromParent` is now `Caller`.
</div>

<div class="compare">

```go title="v1"
err = fmt.Errorf("%s: %w",
	trace.Here(trace.Lfile|
		trace.Lline|trace.Lfunction),
	err)

at := trace.FromParent(1,
	trace.LstdFlags)
```

```go title="v2"
err = fmt.Errorf("%s: %w",
	trace.Here(), err)

at := trace.Caller(1).String()
```

</div>
